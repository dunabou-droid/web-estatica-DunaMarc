# EcoTech Docs

Benvinguts a **EcoTech Docs**, una web de documentació tècnica orientada a l'administració de sistemes i xarxes.

## Objectiu

L'objectiu d'aquesta web és recopilar informació tècnica de manera clara i ordenada perquè un administrador de sistemes pugui consultar diferents procediments i conceptes relacionats amb Linux, xarxes i serveis.

## Continguts

A la web podem trobar les següents seccions:

* **Linux:** usuaris, grups i permisos.
* **Xarxes:** conceptes de TCP/IP i DNS.
* **Serveis:** SSH i HTTP.
* **Articles:** articles tècnics sobre administració de sistemes.

## Tecnologia utilitzada

La web està creada amb **MkDocs**, utilitzant contingut escrit principalment en Markdown.

Posteriorment, MkDocs genera els fitxers HTML, CSS i JavaScript que formen la web estàtica.
