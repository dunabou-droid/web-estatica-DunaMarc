# TCP/IP

TCP/IP és el conjunt de protocols utilitzat per permetre la comunicació entre dispositius d'una xarxa.

## Adreça IP

Una adreça IP identifica un dispositiu dins d'una xarxa.

Exemple:

```text
192.168.1.10
```

## Màscara

Una màscara permet determinar quina part de l'adreça correspon a la xarxa i quina correspon als dispositius.

Exemple:

```text
255.255.255.0
```

## Porta d'enllaç

La porta d'enllaç permet comunicar una xarxa local amb altres xarxes.

Exemple:

```text
192.168.1.1
```

## Comprovar la configuració

A Linux podem utilitzar:

```bash
ip addr
```

I per consultar les rutes:

```bash
ip route
```
