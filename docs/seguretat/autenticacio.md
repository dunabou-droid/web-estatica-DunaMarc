# Autenticació

L'autenticació és el procés que permet comprovar la identitat d'un usuari abans de permetre-li accedir a un sistema o servei.

## Usuari i contrasenya

Un dels sistemes d'autenticació més habituals utilitza un usuari i una contrasenya.

Per exemple:

```text
Usuari: administrador
Contrasenya: ********

```
## Avantatges

L'autenticació multifactor afegeix una capa de protecció addicional.

Si una contrasenya és descoberta, el segon factor pot evitar que una persona no autoritzada accedeixi al compte.
