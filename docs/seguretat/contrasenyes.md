# Contrasenyes segures

Les contrasenyes són una de les primeres mesures de protecció d'un compte.

## Característiques d'una contrasenya segura

Una contrasenya hauria de:

- Tenir una longitud suficient.
- Ser difícil d'endevinar.
- No utilitzar informació personal.
- Ser diferent per a cada servei.
- Evitar paraules molt comunes.
