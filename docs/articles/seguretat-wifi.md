# Seguretat en una xarxa Wi-Fi

## Introducció

Les xarxes Wi-Fi permeten connectar dispositius sense necessitat d'utilitzar cables.

Però també és important configurar-les correctament per evitar accessos no autoritzats.

## Contrasenya del Wi-Fi

La xarxa hauria d'utilitzar una contrasenya segura.

No és recomanable utilitzar contrasenyes fàcils d'endevinar.

## Xifratge

És important utilitzar un sistema de seguretat actual al router.

Quan sigui possible, s'ha d'evitar utilitzar configuracions antigues o insegures.

## Actualitzar el router

El firmware del router també s'ha de mantenir actualitzat.

Les actualitzacions poden corregir problemes de seguretat.

## Xarxa de convidats

Una xarxa de convidats pot separar els dispositius de visitants dels dispositius principals de la xarxa.

Exemple:

```text
                 Router
                   |
          +--------+--------+
          |                 |
          v                 v
    Xarxa principal    Xarxa convidats
          |                 |
          v                 v
     Ordinadors          Visitants
     i servidors
```
## Recomanacions

- Utilitzar una contrasenya segura.
- Mantenir el router actualitzat.
- Utilitzar un sistema de xifratge actual.
- Revisar els dispositius connectats.
- Separar els convidats quan sigui necessari.

## Conclusió

Una configuració adequada de la xarxa Wi-Fi ajuda a protegir les comunicacions i els dispositius connectats.
